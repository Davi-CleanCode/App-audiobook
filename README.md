# Simple Audiobook App 🎧

App simples para tocar áudios sequenciais como um audiobook leve.

## 🎯 Objetivo
- Manipulação de áudio no browser
- Controles play/pause/next
- Estrutura de mini-app

## 🛠 Tecnologias
- HTML
- CSS
- JavaScript

## ▶ Como executar
Abra `index.html`.

## 🚀 Melhorias futuras
- Barra de progresso personalizada
- Lista dinâmica de capítulos
